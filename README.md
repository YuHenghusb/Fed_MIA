# 电子书阅读平台 (E-Book Reading Platform)

一个功能完整的桌面电子书阅读和管理平台，基于 Python Tkinter 开发，支持用户认证、书籍上传审核、在线阅读和阅读记录跟踪。

## 🌟 主要功能

### 用户端功能
- **用户认证系统**
  - 用户注册和登录
  - 邮箱验证
  - 密码加密存储（使用 bcrypt）
  - 密码修改和账户找回

- **书籍浏览和阅读**
  - 书籍搜索（按书名、作者查询）
  - 在线阅读器
  - 阅读进度保存和恢复
  - 阅读记录管理

- **书籍上传**
  - 用户可上传新书籍
  - 提交后等待管理员审核
  - 查看上传记录和审核状态

- **账户管理**
  - 修改密码
  - 注销账户
  - 个人信息查看

### 管理员功能
- **书籍审核**
  - 查看待审核的书籍
  - 审核通过或拒绝书籍
  - 管理已审核的书籍

- **用户管理**
  - 搜索和查看用户信息
  - 删除违规用户
  - 管理用户数据

- **数据管理**
  - 查看书籍库和用户库
  - 删除书籍和用户数据

## 📋 项目结构

```
Fed_MIA/
├── root.py                 # 应用程序入口
```

## 🛠 技术栈

- **GUI 框架**: Tkinter（Python 标准库）
- **数据库**: MySQL（阿里云 RDS）
- **数据库驱动**: PyMySQL
- **密码加密**: bcrypt
- **邮箱验证**: SMTP 邮件服务
- **开发语言**: Python 3.x

## 📦 依赖项

```bash
pip install pymysql bcrypt
```

## 🚀 使用方法

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行应用
```bash
python root.py
```

### 首次使用
1. 启动应用后，选择"注册新用户"
2. 填写注册信息，获取邮箱验证码
3. 完成注册后登录
4. 普通用户可浏览书籍、上传书籍
5. 管理员可进行审核管理操作

## 🔐 安全特性

- ✅ 密码使用 bcrypt 加密存储
- ✅ 邮箱验证码认证
- ✅ 用户数据隔离
- ✅ SQL 参数化查询防止 SQL 注入

## 📝 数据库设计

### 主要表结构

**users_date_1**
- username: 用户名
- password: 加密后的密码
- email: 邮箱地址

**book_date**
- book_name: 书名
- author_name: 作者
- lorder: 上传者

**users_uplord**
- book_name: 书名
- author_name: 作者
- user_name: 上传用户
- state: 审核状态 (new/pass/fail)

**[username]_date**
- book_name: 书名
- author_name: 作者
- record: 阅读页数

## 🎯 核心模块说明

### root.py
应用入口点，初始化 Tkinter 主窗口并启动登录界面。

### loging.py
